
== CB_SVLIT：编译期 String_View 字面量 ==
CB_SVLIT("hello")：count = 5，内容 = |hello|
CB_SVLIT("")：count = 0
CB_SVLIT_STATIC("static-literal")：count = 14，内容 = |static-literal|
与 cb_sv_from_cstr("hello") 等价 -> 1
CB_SVLIT("中文")：count = 6（多字节字面量按字节计长）
两个字面量可直接比较 -> 1

== cb_cmd_extend / cb_cmd_free ==
extend 后 a.count = 5
a.items[0] = cc
a.items[1] = -c
a.items[2] = main.c
a.items[3] = -o
a.items[4] = main.o
cmd_free 清空句柄 items==NULL/count==0/capacity==0 = 1/1/1
两个空 cmd extend 后 x.count = 0

== cb_nanos_since_unspecified_epoch ==
时间戳单调递增 = 1
起点非零 = 1
纳秒差换算成微秒是合理量级（0 < x < 60s）= 1

== cb_needs_rebuild ==
写出 out.bin -> 1
写出 in.txt -> 1
输出不存在时返回 1 -> 1
输入不存在时返回 -1 -> -1
返回值为 0 或 1 -> 1

== cb_procs_wait_and_reset ==
异步起第一条 -> 1
异步起第二条 -> 1
procs 里有 2 个进程
wait_and_reset -> 1
重置后 procs.count = 0
数组内存保留可复用（items != NULL）= 1

== cb_cmd_to_sb：只渲染 argv ==
空命令 -> ||
cb__cmd_append 传入 5 个字面量参数后 cmd.count = 5
cb_cmd_to_sb -> |cc -c 'my file.c' -o out.o|

== cb_cmd_run_opt / cb__cmd_run_opt_with_location 直接调用 ==
cb_cmd_run_opt(.dont_reset = true) -> 1
dont_reset 时 cmd.count 保留 = 1
同一个 cmd 再跑一次（默认重置）-> 1
默认重置后 cmd.count = 0
cb__cmd_run_opt_with_location(.stdout_path/.stderr_path, __FILE__, __LINE__) -> 1
stdout 文件被创建（noop 命令不写东西）= 1，大小 = 0
stderr 文件被创建，大小 = 0

== .stderr_path：stderr 单独落文件，stdout 保持空 ==
cb_cmd_run_opt(.stdout_path + .stderr_path) -> 1
读回 stdout 文件 -> 1，字节数 = 0（应为 0）
读回 stderr 文件 -> 1，含 ERR-MARK = 1

== .stdin_path：stdin 从文件来，stdout 到文件去 ==
写 opt_in.txt -> 1
cb_cmd_run_opt(.stdin_path + .stdout_path) -> 1
读回 opt_out.txt -> 1，含 delta = 1，含 bravo = 1，行数 = 2

== .max_procs：异步节流 ==
第 1 次异步启动 -> 1，池中进程数 = 1（max_procs = 1，所以每次都先等上一个退出）
第 2 次异步启动 -> 1，池中进程数 = 1（max_procs = 1，所以每次都先等上一个退出）
第 3 次异步启动 -> 1，池中进程数 = 1（max_procs = 1，所以每次都先等上一个退出）
cb_procs_wait_and_reset -> 1，重置后 procs.count = 0
